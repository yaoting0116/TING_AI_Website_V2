  • 主角是一個小圓形，起始於畫面中央，使用滑鼠或觸控移動主角到畫面任意位置。
  • 畫面會隨機產生圓形、正方形、三角形，每個形狀有大小。
  • 當你碰到比你「小」的形狀並吃掉它：視為成功，會得到分數。

  • 當你成功吃下任意 3 個形狀時，你會長大一次，吃掉會重置連續扣分的次數。
  • 分數達 10000 分即通關。
